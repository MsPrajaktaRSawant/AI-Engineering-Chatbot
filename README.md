# ⚡ AI Spark – AI Engineering Tutor

**Your Intelligent Companion for Mastering AI Engineering**

AI Spark is an AI-powered learning assistant designed to help aspiring AI Engineers learn and explore important concepts in Python, Machine Learning, Deep Learning, NLP, Transformers, Large Language Models (LLMs), Embeddings, Vector Databases, Retrieval-Augmented Generation (RAG), AI Agents, and MLOps.

It uses Retrieval-Augmented Generation (RAG) to provide context-aware answers based on curated AI Engineering learning materials.

**Think Smarter. Build Better. Engineer the Future.**

---

## 🚀 Key Features

- **AI-Powered Chatbot:** Ask questions about AI Engineering and receive contextual answers.
- **RAG-Based Architecture:** Retrieves relevant information from a knowledge base before generating responses.
- **Document-Based Knowledge:** Uses structured PDF learning resources as its knowledge source.
- **Semantic Search:** Finds relevant content using vector embeddings.
- **Conversational Experience:** Supports interactive question-and-answer sessions.
- **AI Learning Topics:** Covers fundamental and advanced AI Engineering concepts.
- **Modern Interface:** Built with Streamlit for a simple and interactive user experience.

- **LLM Model:** GPT-OSS-20B
- **Embeddings:** Sentence Transformers (`all-MiniLM-L6-v2`)

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/MsPrajaktaRSawant/AI-Engineering-Chatbot.git
```

### 2. Navigate to the project directory

```bash
cd AI-Engineering-Chatbot
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

Windows PowerShell:

```bash
.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure environment variables

Create a `.env` file and add your Groq API key:

```env
GROQ_API_KEY=your_groq_api_key
```

Never commit your API key or other credentials to GitHub.

### 7. Run the application

```bash
streamlit run app.py
```

*Note: Update the entry-point filename if your Streamlit application uses a different filename.*
